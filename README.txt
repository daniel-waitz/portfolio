Daniel Willy Waitz - portfolio site

HOW TO PREVIEW
  Unzip this folder, then double-click index.html. Everything runs in the browser, no install needed.

BEFORE THE CONTACT FORM CAN SEND
  Open index.html, search for FORM_ENDPOINT_PLACEHOLDER and replace it with the URL from your
  form service (for example Formspree). Until then the form shows the "email me directly" message
  instead of sending, and the Email me button still works.

TO PUBLISH
  Upload everything in this folder to your GitHub repository, replacing the old files.

FILES
  index.html            the page
  assets/css/style.css  all styling (light and dark theme colours are at the top)
  assets/js/app.js      all behaviour (theme switch, menu, background lines, projects, contact form)
  assets/img            headshot, project screenshots
  assets/logos          tool logos
  assets/fonts          Zodiak and General Sans (Fontshare)
