Daniel Willy Waitz - portfolio site
Live at https://danielwaitz.com/

HOW TO PREVIEW
  Unzip this folder, then double-click index.html. Everything runs in the browser, no install needed.
  (The 404 page uses site-root paths, so it only looks right once it is on danielwaitz.com.)

CONTACT FORM
  Messages are sent through Formgong (action https://formgong.com/submit, with your access key in a
  hidden field). After publishing, send yourself one test message to confirm it arrives.

TO PUBLISH ON GITHUB PAGES
  Upload everything in this folder to the top level of your repository, replacing the old files.
  Keep the CNAME file (it contains danielwaitz.com). GitHub Pages needs it for your custom domain,
  so check it is still in the repository after any redesign or file replacement.

FILES
  index.html            the page
  404.html              shown for any address that doesn't exist
  CNAME                 your custom domain for GitHub Pages
  robots.txt            tells search engines they may index the site, and where the sitemap is
  sitemap.xml           the list of pages for search engines
  og-preview.jpg        the 1200x630 picture shown when the link is shared
  assets/css/style.css  all styling (light and dark theme colours are at the top)
  assets/js/app.js      all behaviour (theme switch, menu, background lines, projects, contact form)
  assets/img            headshot, project screenshots, testimonial photos
  assets/logos          tool logos
  assets/fonts          Zodiak and General Sans (Fontshare)
