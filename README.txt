Daniel Willy Waitz - portfolio site (draft)

HOW TO PREVIEW
  Unzip this folder, then double-click index.html. Everything runs in the browser, no install needed.

WHAT STILL NEEDS YOUR INPUT
  1. Check that the three Make embeds show on your computer (they load from make.com).
  2. The V2 dashboard images show an agent named "Daniel" in the sample data.
  3. To edit text or quotes, change build.py / template.html and run: python3 build.py (or ask Claude).

FILES
  index.html            the page (generated by build.py from template.html)
  assets/css/style.css  all styling
  assets/js/app.js      all behavior (tools belt, timeline, conference carousel, dashboard, testimonials)
  assets/img            headshot, conference previews, dashboard images
  assets/logos          muted + original SVG for every tool
  assets/fonts          Zodiak and General Sans (Fontshare)
